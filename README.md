# Smart-AI-Attendance-System
Project Description

The Smart AI Attendance System is an AI-powered attendance management application developed using Python and OpenCV. The system uses facial recognition technology to automatically detect and recognize student faces and mark attendance digitally. This project helps reduce manual attendance work, improves accuracy, saves time, and provides an efficient attendance management solution for educational institutions.

The project includes face detection, face recognition, student registration, attendance recording, and report generation functionalities. A graphical user interface (GUI) is also implemented to make the system user-friendly and easy to operate.

System Modules
1. Student Registration Module

Stores student details and captures facial data for training.

2. Face Detection Module

Detects human faces using OpenCV Haar Cascade classifier.

3. Face Recognition Module

Recognizes faces using the LBPH Face Recognizer algorithm.

4. Attendance Management Module

Automatically marks attendance with date and time.

5. Report Generation Module

Generates attendance reports in Excel format.
